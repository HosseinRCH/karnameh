کارنامه ویندوز ۰.۷.۱ — نسخهٔ پاک (بدون دادهٔ شخصی)
=====================================================

این نسخه برای اجرا روی سیستم‌های مشترک/شرکتی ساخته شده است: هیچ دادهٔ
کارنامه‌ای داخل فایل EXE نیست. بار اول یک میزکار خالی می‌سازد و شما داده‌های
خودتان را از فایل JSON وارد می‌کنید.

اجرا
----
1. فایل Karnameh-0.7.1-clean-win-portable.exe را دابل‌کلیک کنید.
2. اگر SmartScreen هشدار داد: More info → Run anyway.
3. برنامه یک پوشهٔ «Karnameh-Data» کنار EXE می‌سازد؛ همهٔ داده‌ها و حافظهٔ
   داخلی برنامه فقط داخل همین پوشه است.

وارد کردن داده‌ها
-----------------
1. فایل JSON خود را (همان karnameh-export) روی سیستم یا فلش داشته باشید.
2. در برنامه: «بیشتر ← داده‌ها ← ایمپورت JSON» و فایل را انتخاب کنید.
3. داده‌ها داخل Karnameh-Data ذخیره می‌شوند. فایل JSON اصلی را می‌توانید
   بعد از ایمپورت پاک کنید (اگر جای موقتی است).

پاک‌کردن کامل از روی سیستم شرکت
--------------------------------
1. برنامه را کامل ببندید.
2. روی Delete-Karnameh-Data.cmd دابل‌کلیک کنید.
   این اسکریپت پوشهٔ Karnameh-Data، مسیر جایگزین %APPDATA%\Karnameh و
   %LOCALAPPDATA%\Karnameh و پوشه‌های موقت استخراج را پاک می‌کند.
3. فایل JSON واردشده (اگر روی دیسک کپی کرده‌اید) و در صورت نیاز همین EXE و
   پوشه را هم حذف کنید.
4. اگر گزارشی را در کلیپ‌بورد کپی کرده‌اید (Google Sheets)، کلیپ‌بورد را پاک کنید.

نکته
----
- چون این نسخه هیچ داده‌ای داخل EXE ندارد، اگر EXE را هم روی سیستم بگذارید،
  دادهٔ شخصی داخل آن نیست؛ دادهٔ شما فقط در Karnameh-Data است.
- برای بردن نتیجهٔ کار به خانه: «اکسپورت JSON» بگیرید یا کل پوشهٔ
  Karnameh-Data را همراه EXE کپی کنید.
